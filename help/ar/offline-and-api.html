الاستخراج المحلي والخصوصية

محرك PaddleOCR أو Windows

يتعرف المحركان على العربية والإنجليزية والفرنسية محلياً. يستخدم Paddle نماذج مضمّنة ومفسر Python خاصاً؛ ولا تحتاج إلى تثبيت Python بنفسك. يحتاج محرك Windows إلى مكونات التعرف على النص الخاصة باللغات المطلوبة. قد يتطلب تنزيل الحزم الناقصة الإنترنت قبل استخدامها دون اتصال. حزمة لغة العرض ومكوّن التعرف على النص ليسا بالضرورة الشيء نفسه.

اختر إعدادات التطبيق > استخراج النص > محرك استخراج النصوص وملف لغة الاستخراج الافتراضي. يمكن اختيار نماذج العربية والإنجليزية والفرنسية على حدة في التثبيت المخصص، ويحتاج الملف متعدد اللغات إلى النماذج المناسبة. لا يمكن اختيار Paddle إذا لم يكن مثبتاً؛ أعد تشغيل التثبيت المخصص لإضافته. لا يوفّر Windows تقديرات الثقة أو مصنف اتجاه الصفحة الخاص بـ Paddle. عند استخدامه مع صورة مدارة، صحح اتجاه المصدر قبل الاستخراج. راجع حل المشكلات للحزم الناقصة والنتائج الضعيفة.

إبقاء النص محلياً

أبقِ الإعدادات > تحسين النص عبر الإنترنت والخصوصية > وضع عدم الاتصال فقط مفعّلاً إذا لم ترغب في التحسين عبر الإنترنت. يمنع ذلك أيضاً اختبار مفاتيح الخدمات. لكنه لا يعطّل التحقق المستقل من التحديثات أو الروابط التي تفتحها بنفسك. لا يحتاج الاستخراج المحلي إلى حساب أو اشتراك أو مفتاح.

التحسين الاختياري باستخدام خدمتك

  1. افتح إعدادات التحسين والخصوصية، واختر OpenAI أو Gemini أو Groq واقرأ تنبيه الخدمة.
  2. أنشئ مفتاحك في حسابك باستخدام رابط الخدمة الرسمي، ثم أدخله واختر نموذجاً متاحاً لحسابك. لا يوجد مفتاح مشترك من TextBridge.
  3. عندما ترغب في الاتصال ألغِ وضع عدم الاتصال فقط. يرسل اختبار المفتاح عينة ثابتة لا مستندك، وقد يستهلك حصة أو يترتب عليه رسم. لا يتطلب الاستخراج المحلي أي اختبار مفتاح.
  4. لتحسين مستند، فعّل الإذن بإرسال نصه وخيار تحسين النص عبر الخدمة، ثم احفظ. احفظ قبل تغيير الخدمة للاحتفاظ بمفتاح ونموذج كل خدمة على حدة.
  5. حدد النص المطلوب في المحرر، أو اتركه دون تحديد لإرسال نص المحرر. اختر استخراج النص > تحسين النص باستخدام خدمة عبر الإنترنت. راجع الخدمة وعدد الأحرف والتأكيد قبل الإرسال.
  6. راجع النص الأصلي والمقترح؛ يستبدل تطبيق التصحيح النص المرسل، ويحتفظ الإلغاء بالأصل. يعيد التراجع النص قبل التصحيح. يلغي أمر إلغاء الطلب في قائمة استخراج النص الطلب المعلّق، لكن قد تحاسب الخدمة على طلب وصل إليها بالفعل.

يُرسل النص، وليس الصورة أو PDF الأصلي. لا ينتقل البرنامج تلقائياً إلى خدمة أخرى أو بديل مدفوع. قد يغيّر التصحيح الأسماء والحقائق والأرقام؛ راجع المقترحات. الحد في التطبيق 12,000 حرف للطلب، وقد تتطلب الخدمة أقل.

المفاتيح وشروط الخدمات

تُحجب المفاتيح وتُشفّر لحساب Windows الحالي باستخدام Windows Data Protection API، منفصلةً عن settings.json. امسح حقل مفتاح الخدمة المختارة واحفظ لحذفه. لا يؤدي تفعيل وضع عدم الاتصال إلى حذف المفاتيح. نجاح الاختبار لا يضمن استخداماً مجانياً غير محدود أو ملاءمة شروط الاحتفاظ بالبيانات. راجع الخطة والخصوصية والحدود الحالية للخدمة قبل إرسال نص حساس.
