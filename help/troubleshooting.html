Troubleshooting

The selected OCR engine is unavailable

Open Help > Runtime Diagnostics. For Paddle, rerun Custom setup with the bundled runtime selected, or keep the complete portable folder together. Do not copy TextBridge.exe alone. For Windows OCR, add the missing language's OCR capability in Windows language settings, then reopen TextBridge. Installing a language can require Internet access and permission from your administrator. Select only installed OCR languages; a combined profile requires its requested packs.

No text or poor recognition

  • Check the selected document language and engine. Start with one clear page of printed text.
  • Use a sharper, larger image with correct orientation and sufficient contrast. Paddle automatic orientation is available in OCR settings; Windows input may need rotating beforehand.
  • For a damaged PDF text layer or an incorrectly rotated scan, clear Use existing PDF text when available to try full-page OCR.
  • Try deskew or grayscale in OCR settings when appropriate. Compare results and review names/numbers. Handwriting, calligraphy, tables and complex columns are not reliable automatic use cases.

F4 finds nothing

Windows OCR has no confidence scores. Paddle may have found no spans below the review threshold, or editing may have invalidated stored positions. This does not establish error-free text. Read the result yourself; recognize again to refresh review locations.

A message is not spoken

Press Shift+F6 for the current status. Check Announce OCR progress under App settings > Accessibility and your screen reader's speech mode. F6 returns to the editor. Disable startup/exit sounds if they mask speech. Report the reader/version, interface language, exact keys and what was or was not spoken.

Saving or export fails

Choose a writable folder and a new filename; close any application locking the destination file. Keep the source file available for searchable PDF export. Review the error before retrying. Searchable PDF export uses the source pages, not your editor corrections. Save edited text or Word separately. For Word export remember Ctrl+E; HTML, Markdown and PDF are in File > Export.

Online correction fails

Local OCR remains available. Check the provider, model, key and explicit sharing permissions in Online correction and privacy. A key test uses a fixed sample and can incur a charge; do not send private text just to troubleshoot. Read the provider's error about account limits, model access or connectivity. A failed or cancelled request preserves the local text.

Updates and help

Only newer stable releases are offered automatically. A preview can remain downloadable without being a stable update. The update requires HTTPS, a matching checksum and your acceptance before installation. Help pages are local; if one is missing, reinstall the complete package. If the default browser cannot open it, open the help folder beside TextBridge.exe and choose index.html.

Still stuck?

Use Report a Problem. Include the engine, language, reproducible steps and exact error. Share only a non-private sample you are allowed to distribute, if you decide one is needed; the app does not attach it automatically.

Long documents

PDFs are processed page by page without a fixed page-count or total-duration cutoff. Completed pages stay in the editor while later pages continue. The first result can take longer while Paddle models load and the page is prepared; choose timed progress announcements to follow work during that wait. Escape lets you stop. Select the appropriate document language; combined language profiles require additional work.
