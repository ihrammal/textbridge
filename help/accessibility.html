Accessibility Guide

Use this guide for keyboard access, screen-reader feedback and reading appearance. Actual compatibility must be checked with the screen reader and configuration you use; automated accessibility checks alone are not a completed screen-reader test.

Keyboard route through a document

  1. Open with Ctrl+O, select the source and return to the editor.
  2. Choose the document language from Recognize, then press Ctrl+R. Allow time for the first Paddle recognition.
  3. Read using your screen reader's editor commands. F6 returns to the editor without clearing its selection.
  4. Press Shift+F6 to review progress, completion or an error. With the status bar hidden this opens a dialog; Escape returns to your work.
  5. Review and save with Ctrl+S or export Word with Ctrl+E.

Announcements and focus

Under Settings > App settings > Accessibility, choose whether to announce OCR progress and play startup/exit sounds. Screen-reader support itself stays enabled. The status bar is hidden by default; View > Show status bar makes it visible. Progress announcements do not require a visible bar. Settings dialogs offer Save and Cancel; Escape cancels, and closing a dialog should return focus to the previous control.

If a progress announcement is missed, use Shift+F6. If speech is interrupted by a sound, disable that sound and report the reader/version and steps. Do not interpret silence as successful OCR; read the status and result.

Recognition review

F4 and Shift+F4 select text below the configured confidence threshold and announce its position and line estimate. Arabic review can select a whole line. Editing the result invalidates those stored locations; recognize again to refresh them. Windows OCR supplies no confidence, so these commands cannot identify its doubtful words. Review > Review text to check also uses basic suspicious-text rules; this is not a guarantee that all other text is correct.

Fonts, contrast and scaling

Settings > Accessibility settings opens the single Accessibility tab. Its section buttons jump to screen-reader options, low-vision controls, or sounds and messages. View > Reading appearance opens the font and contrast group in that same tab. Choose document font, 10–72 point text, bold text, interface size (12–32), or Windows/default, light, dark, yellow-on-black and cream reading colours. Windows high contrast takes priority. Accessible reading mode increases document size and line spacing. Dialogs support keyboard navigation and scrolling; report clipped controls with your display scale and screen resolution.

Arabic and exported documents

General settings choose Arabic or English for the interface. Arabic uses right-to-left controls; source language remains a separate OCR choice. Read mixed Arabic/Latin text and numerals carefully. Word marks detected Arabic paragraphs as right-to-left. Searchable PDF preserves appearance and searchable text; it is not a guarantee of a tagged, fully accessible PDF. Check exported files in the reader where you intend to use them.

Reading this help

Help opens in your default browser. Use its heading, landmark and link navigation. Each page has a skip-to-content link, local topic navigation and a link to the same page in Arabic/English. Ctrl+P prints a page. External provider and support sites require the Internet; the help itself does not.

Choose how often progress is spoken

Progress announcement frequency is in the screen-reader group of the single Accessibility tab. Choose every completed page, or every 5, 10, 15, 30 or 60 seconds. Timed modes can repeat the current page and completed-page percentage while one slow page is still processing. Each-page mode waits for completion. Turning Announce OCR progress off disables automatic progress speech but keeps visual progress and Shift+F6 available. Recognition start and completion feedback is separate from interval throttling when announcements are enabled.

The editor becomes read-only while pages arrive, so you can read and copy without corrupting the growing result. Saving stores the pages currently available; pages added later remain unsaved. Your selection and scroll position are retained when pages are appended and when recognition finishes. Batch progress also identifies the current file and page.

Stop recognition

Press Escape outside menus to ask to stop recognition. Yes stops it and keeps completed pages; No or Cancel continues. If a menu is open, Escape closes that menu level first. Exiting during recognition also asks to stop, then lets you save available text before closing.
