6. Local processing and optional online services

PaddleOCR and Windows OCR process documents on your computer. Installed OCR models work offline. Installing missing Windows OCR language capabilities may require Internet access. Optional online correction requires your own provider account/key, enabled sharing settings and confirmation before text is sent. Correction sends the chosen text to the selected provider, not the original image or PDF. Testing an API key sends a fixed sample, not your document. Provider terms, retention policies, charges and quotas apply separately. Offline only mode blocks online correction and API-key tests; it does not block separate update checks or websites you choose to open. See the bundled Offline OCR and Privacy help for settings, key storage and request details.

7. Updates and installation choices

Automatic update checks are enabled by default and can be turned off in app settings. A check contacts the configured update service. TextBridge asks before downloading and installing an offered update. If you agree, it downloads the installer, verifies its SHA-256 checksum and starts installation. You can review or save unsaved work before installation; Windows may ask for administrator permission. A correction may keep the displayed version number and use a higher internal build revision. Express setup uses the stated recommended options; Custom setup lets you choose the OCR engine, Paddle language models, installation folder and shortcuts. Read the setup screen before starting installation.
