Offline OCR and Privacy

PaddleOCR or Windows OCR

Both engines recognize Arabic, English and French locally. Paddle uses models bundled with the installer and a private Python runtime; you do not install Python yourself. Windows OCR needs the matching Windows OCR language capabilities already installed. Adding a missing Windows language/OCR pack can require an Internet connection before offline use. Language display packs and OCR capabilities are not always the same thing.

Choose Settings > App settings > OCR > Recognition engine and Default OCR language profile. Custom setup can install Arabic, English and French models individually; a combined profile needs the corresponding installed models. A missing Paddle runtime cannot be selected; rerun Custom setup to add it. Windows does not provide confidence estimates or Paddle's automatic orientation classifier. For rotated Windows input, rotate the source before recognition. See troubleshooting for missing packs and poor results.

Keep text local

Leave Settings > Online correction and privacy > Offline only mode enabled if you do not want to use online correction. This also prevents API-key tests. It does not disable separate update checks or links you deliberately open in a browser. OCR does not require an account, subscription or API key.

Optional correction with your own provider

  1. Open Settings > Online correction and privacy, choose OpenAI, Gemini or Groq, and read the selected provider's notice.
  2. Create a key in your own account using the provider's official key link. Enter the key and a model available to that account. There is no shared TextBridge key.
  3. When you want online access, clear Offline only mode. Test API key sends a fixed sample, not your document; it can consume quota or incur a charge. No test request is needed for local OCR.
  4. To correct a document, enable both document-sharing permission and API-assisted OCR text correction, then Save. Save before changing provider so each key/model is retained separately.
  5. Select text in the editor, or leave no selection to use the editor text. Choose Recognize > Improve text with online service. Review the selected provider, character count and confirmation before sending.
  6. Review original and proposed text; Apply correction replaces the sent text, while Cancel keeps the original. Undo restores an applied correction. Recognize > Cancel online request cancels a pending request; a provider may still bill a request it already received.

The correction request sends text, not the original image/PDF. TextBridge does not automatically switch providers or fall back to a paid service. Corrections can change names, facts and numbers; review every proposal. The app limits a request to 12,000 characters, and a provider may require less.

Keys and provider terms

Keys are masked and encrypted for the current Windows user using Windows Data Protection API, separately from settings.json. Clear the chosen provider's key field and Save to remove its saved key. Enabling Offline only mode does not delete keys. A successful key test does not establish unlimited free use, billing status or suitable data-retention terms. Check your provider's current plan, privacy and limits before sending sensitive text.
