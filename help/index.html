TextBridge Help

TextBridge is an accessibility-first Windows OCR application by Iman Rammal.

Getting started

  1. Choose File, Open.
  2. Select a PDF or image.
  3. Choose Recognize, Read text from document (Ctrl+R).
  4. Review the recognized text.
  5. Choose File, Export to save Word, HTML, Markdown or searchable PDF.

PDF recognition

TextBridge combines existing PDF text with scanned content on the same page. Pages containing images also undergo OCR, so searchable scans and documents with pictures can take longer. Review reading order for columns and complex layouts. For rotated or skewed scans that need additional correction, turn off Use existing PDF text when available in OCR preferences to recognize the full page.

Saving your work

Opening another document, recognizing again, or closing with unsaved text offers Save, Discard (No), and Cancel. Cancel keeps your current text. A cancelled or failed save keeps your work open. Save As cancellation keeps the previous save location.

Accessibility

All essential functions are intended to be available from the keyboard and exposed to screen readers. Use Settings > App settings > Accessibility for announcements, reading mode and startup or exit sounds. Use the Low vision tab for font size and contrast. Windows high contrast is always respected. View > Reading appearance opens the same Low vision controls.

Free offline OCR and optional APIs

Arabic, English and French OCR works offline without an account or key. Optional OpenAI, Gemini and Groq text correction uses your own keys. Each provider has Create API key and Test API key actions. See offline OCR and API setup.

Privacy

Core OCR is designed to run locally. Optional API features will clearly identify when document information may leave the computer.
