TextBridge Help

Read, edit and save text from Arabic, English and French images and PDFs. This guide is included with TextBridge 1.1.0 and opens in your default browser without an Internet connection.

Your first document

  1. Choose File > Open (Ctrl+O) and select an image or PDF.
  2. Under Recognize > Document language, select the language or combination used in the document. This does not change the interface language.
  3. Choose Recognize > Read text from document (Ctrl+R). Wait for completion; the first Paddle recognition takes longer while models load.
  4. Read and edit the result. Check names, numbers, punctuation and reading order. F4 and Shift+F4 visit low-confidence text where the engine provides confidence. They cannot find every error.
  5. Press Ctrl+S to save editable UTF-8 text. Use File > Export for Word, HTML, Markdown or searchable PDF.

Choose how to install

Express installs bundled PaddleOCR and desktop/Start menu shortcuts after you select Install. Custom lets you choose PaddleOCR or Windows OCR, the Paddle language models, folder and shortcuts. Starting TextBridge after setup is optional. The download contains Paddle even if you omit it during installation.

Paddle includes Arabic, English and French/Latin models. Windows OCR uses installed Windows OCR language packs. Both recognize locally. Choose the installed engine under Settings > App settings > OCR. See engines and privacy.

Save and export safely

Ctrl+Shift+S saves text under a new name. Ctrl+E exports a Word document directly; other formats are in the Export submenu. Save your edits as text or Word. Searchable PDF is created from the source pages and a recognized text layer; it is not a PDF version of your edited editor text.

Before opening another file, recognizing again or closing with unsaved edits, choose Yes to save, No to discard, or Cancel to keep working. Cancelling or failing to save keeps your work open.

PDFs and reading order

By default TextBridge preserves existing PDF text and recognizes scanned content. In App settings > OCR, clear Use existing PDF text when available if a damaged text layer or rotated scan needs full-page recognition. Complex columns and tables may need editing. Searchable PDF retains page appearance; it does not guarantee tagged headings, accessible table structure or an ideal screen-reader reading order. For structured reading, consider Word or HTML and review the result.

Keyboard and reading settings

Alt or F10 enters or leaves the menu bar. Use arrows and Enter inside menus; Escape closes one submenu level. F6 returns to the editor; Shift+F6 reads the current status, including when the status bar is hidden. Use View > Reading appearance for fonts and contrast. The General tab in App settings changes English/Arabic interface language.

See the complete shortcut list and accessibility guide. A feature being exposed to accessibility tools does not establish that it has passed every screen reader and configuration.

When something goes wrong

Start with troubleshooting. Help > Runtime Diagnostics checks the selected OCR engine and supporting tools. Help > Report a Problem prepares a report for you to review; nothing is sent automatically. Help > Check for Updates checks for newer stable versions and asks before installation.
