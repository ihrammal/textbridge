Keyboard Shortcuts

Use these keys in the main TextBridge window unless a dialog is specified. Open this page from Help > Keyboard Shortcuts. Combinations containing Ctrl or Alt use the named modifier, not your screen-reader modifier.

Ctrl+SSave editor text as UTF-8 text.

Menus without a mouse

Press Alt or F10, use Left/Right to choose a top-level menu, then Down/Up and Enter. Tab stays in menu navigation. Escape closes one submenu level; Alt or F10 exits the menu chain. In the English interface, Alt+H opens Help; K opens Keyboard Shortcuts and P opens Report a Problem. Arabic menu access letters differ; Alt and the arrow keys work in either language.

Commands available through menus

Open Multiple Files, HTML/Markdown/searchable PDF export, the OCR language profile, online correction/cancellation, review dialog, reading appearance and runtime diagnostics are menu commands without dedicated application shortcuts. Ctrl+E always opens Word export; it does not open the Export submenu.

Screen-reader keys

Use your screen reader's usual reading commands inside the editor. TextBridge does not assign Insert, Caps Lock or the Windows key as application shortcuts. If a command is intercepted, consult your screen reader's keyboard help. F4 review depends on confidence: Windows OCR has no confidence scores, so review its text directly.
