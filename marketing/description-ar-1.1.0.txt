TextBridge 1.1 — استخراج النصوص بالعربية والإنجليزية والفرنسية دون إنترنت

حدّثت TextBridge بإضافة PaddleOCR لتحسين استخراج النصوص محلياً، مع اهتمام خاص بالكلمات والأرقام العربية.

يتضمن هذا التحديث التصحيحي إدراج النص صفحةً بعد صفحة مع إمكانية تعديله، وخيار تحديد تكرار إعلان التقدم، وأزرار التنقل بين الصفحات، وتحسين ملفات المساعدة. يتلقى المستخدم إشعاراً بالتحديث ويبدأ التثبيت بعد موافقته. يبقى رقم الإصدار الظاهر 1.1.0.

افتح صورة أو ملف PDF ممسوحاً ضوئياً، واستخرج النص، ثم راجعه وعدّله واحفظه. يمكنك أيضاً تصديره إلى Word أو HTML أو Markdown أو ملف PDF قابل للبحث والنسخ.

يدعم التطبيق التنقل بلوحة المفاتيح وقارئات الشاشة، مع خيارات لتكبير الخط وتغيير ألوان القراءة.

اختر التثبيت السريع لتثبيت PaddleOCR ونماذج اللغات المضمّنة، أو التثبيت المخصص لاستخدام محرك Windows واختيار الاختصارات التي تريدها. يعمل الخياران دون إنترنت، ويستخدم محرك Windows حزم اللغات المثبّتة على جهازك. يمكنك إنشاء ملفات PDF قابلة للبحث بأيٍّ من المحركين.

راجع الأسماء والأرقام دائماً، فقد تحدث أخطاء في استخراج النص.

لنظام Windows ‏64 بت. مجاني للاستخدام غير التجاري.
