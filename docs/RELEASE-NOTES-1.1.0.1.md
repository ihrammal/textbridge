# TextBridge 1.1.0 — corrected build 1

This is a maintenance correction to TextBridge 1.1.0. The version shown in the app remains 1.1.0; the internal update build is 1.1.0.1 so existing installations can discover the correction.

- Long PDFs insert editable text as each page completes, with plain “Page n of total” headings.
- Progress announcements have a user-selected interval. New pages are followed automatically by default, with Previous/Next page buttons and F7 to reach the latest completed page.
- Normal arrow navigation, selection, cut, copy, paste and delete remain available during recognition. Selections and recent edits temporarily protect the reading position.
- Escape and closing the app offer to stop recognition, retaining completed text. Long documents have no fixed page-count or overall recognition-time cutoff.
- Updated English/Arabic help, keyboard shortcuts, accessibility settings and user agreements.
- Express setup uses recommended Paddle settings. Custom setup offers Paddle or Windows OCR, optional Paddle language models, location and shortcuts.

The full offline package includes Arabic, English and French Paddle models. Windows OCR requires the corresponding installed Windows language packs. Recognition accuracy varies by document; review important text, especially names and numbers. Initial model loading and image-heavy pages can take longer.

Existing users with update checks enabled receive an update prompt. After approval, the app downloads and verifies the installer and starts the update automatically; Windows may request installation permission. Settings and selected installation scope are retained.

Use TextBridge-Setup-1.1.0.1.exe for the corrected installer. The 1.1.0 filename is an identical manual-download alias. The app and installer are unsigned. Free for noncommercial use under the included agreement; third-party components retain their own licenses.
